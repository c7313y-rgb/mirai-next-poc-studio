# 国内の小規模PoCへ配備する

この構成は単一サーバー用です。ソースと設定例は用意していますが、利用するクラウドアカウント・ドメイン・IAM権限・学校の受入は別途必要です。ローカル実行や自動テストの成功を、現場配備の成功とは扱いません。

## 構成と責任

国内のLinuxサーバーで Docker Compose を使用し、CaddyがHTTPSを終端し、アプリは内部ネットワークだけで待ち受けます。SQLiteと画像は暗号化ストレージ上の永続ボリュームに保存します。アプリを複数台に増やす前にはDB・ジョブ処理の再設計が必要です。

運営担当者はDNS、国内保存先、ストレージ暗号化、最小権限IAM、サーバー更新、監視先、費用通知、学校の共有合意を設定します。生徒情報を含む実データや認証鍵を公開リポジトリに入れません。

## 手順

1. Docker/Composeが利用できる国内サーバーを用意します。受信はHTTPS、証明書用HTTP、制限した管理接続だけにします。アプリの3000番ポートは外部公開しません。
2. `deploy/production.env.example` を `.env.production` へコピーし、ドメイン、仮名IDシークレット、画像鍵、別のバックアップ鍵を設定します。鍵はそれぞれ独立した32バイト相当以上の乱数とし、安全な別保管先へ復元手順とともに保管します。設定ファイルは所有者のみ読み書き可能にします。
3. Bedrockの国内モデル、学習利用・保存条件を確認し、利用権限を付与します。IAMロールを使用し、長期アクセスキーの埋込みは避けます。Dockerからロール資格情報を取得できることも確認します。
4. 学校のFQDNをサーバーに向け、下記を実行します。`DOMAIN` は実際のドメインへ置き換えます。デモseedは実行しません。

```bash
DOMAIN=your-school-domain.example docker compose -f compose.production.yml up -d --build
DOMAIN=your-school-domain.example docker compose -f compose.production.yml exec app npm run create-admin -- school-admin
DOMAIN=your-school-domain.example docker compose -f compose.production.yml exec app npm run production-check
```

5. アカウントを発行し、初期PW変更・停止・再発行を通しで確認します。生徒の氏名と仮名IDの対応は学校側で管理します。
6. 実端末で画像提出と実AIを確認し、TLS、API権限、1クラス同時提出、想定100名操作を受入試験します。
7. バックアップのログを外部監視へ接続します。`backup` サービスは24時間ごとに暗号化バックアップを作ります。同じサーバー内のボリュームだけでは障害対策として不十分なので、暗号化ファイルをアクセス制御された国内の別保存先へ複製します。

## バックアップと復元確認

`BACKUP_ENCRYPTION_KEY` は全体バックアップの暗号化鍵です。画像の `DATA_ENCRYPTION_KEY` と混同しません。バックアップはDBスナップショットと、そのDBが参照する画像を含みます。画像が欠ければ成功扱いにしません。保存期間は日数で管理します。旧形式の平文バックアップは自動変換・自動削除しません。一時領域には対象データの約2倍の空き容量を確保してください。読み取り専用ボリュームからのWALバックアップはアプリ稼働中に行い、実コンテナ上でも確認します。

```bash
npm run backup
npm run restore-check -- /path/to/2026-09-18T00-00-00-000Z.mirai-backup.enc
```

`restore-check` は隔離した一時領域で復号し、DB整合性・参照画像・画像鍵を検証して削除します。実DBは上書きしません。実復旧は、サービス停止、対象バックアップ選定、隔離環境への復元、件数照合、管理者確認、本番切替の順に担当者が実施します。復旧時間・許容するデータ損失は学校と合意してください。

## AI予算と初月の試行

初月はHaiku系のOCRを実手帳で評価し、必要な難例だけSonnet系へ切り替える計画です。例の月3,000 API呼出枠は再試行も数え、OCRとコメントは別々に消費します。320人が週2回画像提出すると原則月5,504呼出以上になるため、3,000枠は初月の小規模試行向けです。運用確認後に枠と予算を見直します。

件数上限は円建ての課金保証ではありません。AWSの費用通知、入力長・画像数制限、再試行制御と合わせて管理し、予算超過が見込まれる場合は新規AI処理を停止して文字入力・人の確認へ切り替えます。

## 外部連携

mirAIへの自動送信は行いません。標準CSV/JSONのデータ辞書を相手と確定し、アクセス制御付き共有で渡して受領結果を記録します。APIのURL・認証・利用料・訂正/削除仕様が確定するまで、自動同期を稼働済みとは表示しません。
