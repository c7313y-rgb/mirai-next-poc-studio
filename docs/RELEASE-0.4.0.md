# 0.4.0 表示改善と探究体験の拡張

2026-09-18。既存PoCの役割別画面、教材化、授業、KPI、標準出力を維持し、追加構想のうち新しい有料APIやデータ契約を必須としない機能を追加しました。承認済みの初月運用込みの予算方針は変更していません。

## 変更内容

| 項目 | 実装 |
|---|---|
| 表示・操作 | ログイン画面の生徒アイコンに全画面用スタイルが混入する不具合を修正。小画面のナビゲーションを開閉式に変更。フォーム、カード、活動手順、表の横幅・折返しとフォーカス表示を調整。入力欄とラベル・補足説明を関連付け |
| 場面を伝える画像 | 企業での教材づくり、地域での体験、手帳での内省の3点を生成し、役割別トップ、テーマ、教材、キャリア、探究画面へ組込み。画像は架空のイメージと表示 |
| 教材変換 | 入力文全体から原文の根拠を抽出し、高校探究・中学総合・高校情報Ⅰの対応候補、3つの資質・能力、4つの探究過程、評価の証拠を持つ草案を作成。教員が自校目標・単元位置を編集し確認して承認 |
| 関心と教材 | 本人の提出済み記録の関心タグと、クラスへ配信済みのテーマを照合。推薦理由を表示し、検索と新着順への切替を用意 |
| 探究4STEP | 目的、計画、現場の事実と感情、手帳で考えたい問い、次の行動を日付付きで保存・編集。自分の提出済み手帳を根拠として関連付け |
| 教員との対話 | 担当生徒の記録確認、本人にも共有する声かけ・面談メモ、予定日と対応状態を追加 |
| 追加の参考指標 | 本人申告の自発的記述の件数・文字数、前後双方の記録人数、教員の継続希望率・回答率・指導負荷を表示。個人本文を含まない報告テキストを保存 |

授業案の作成と推薦はローカルの規則による支援です。文章の意味を全面的に理解するAIや学習指導要領の自動適合認定ではありません。教員の確認が必要です。既存の手帳OCR・コメントを実AIへ切り替えた際の利用料は別に発生します。

## 検証

- 自動テスト72件成功：権限・学校/クラスの分離、教師確認なしの承認拒否、探究記録の本人性と更新競合、推薦データ範囲、デモデータの投入制限などを含みます。
- ブラウザで幅390 / 768 / 1280pxを確認。ログイン、ナビゲーション、テーマ検索、教材編集・学校提供・教員採用と承認、探究保存と担当教員の閲覧、共有メモ保存を操作しました。
- クライアントの本番ビルドを確認。実AI・本番クラウド・学校端末の受入を完了したという意味ではありません。

## 更新時の扱い

- 既存DBの教材に対応候補を保存する列を追加し、探究・面談・教員調査のテーブルを追加します。既存データは削除しません。
- 旧教材は対応候補を教員が確認していない状態です。新しい授業を作る前に自校目標・単元位置を記入し、確認・再承認してください。作成済みの授業は作成時の教材内容を維持します。
- `npm run demo` は探究4段階の架空サンプルを追加します。既存デモへ追加する場合は `npm run seed:journey`。明示的なデモ環境・既知のデモ学校/アカウント以外では実行できず、再実行しても重複しません。継続希望率や自発的記述の実績は生成しません。
- 共有メモは生徒にも表示されます。企業へ個人の探究記録や面談メモを提供しません。探究本文や面談メモを標準mirAI出力へ自動追加しません。

実企業のネットワーク、体験の受入契約・手配、入試データベース、3年間の保管同意と学年移管、外部サービスの本番APIは今回の追加実装に含みません。詳細は[構想対応表](DIRECTION-V2.md)、[教材設計の根拠](CURRICULUM-GUIDANCE.md)、[画像と生成プロンプト](ASSETS.md)、[運用手順](OPERATIONS.md)を参照してください。
