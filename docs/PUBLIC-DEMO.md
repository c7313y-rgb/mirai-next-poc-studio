# GitHub公開デモ

公開URL：<https://c7313y-rgb.github.io/mirai-next-poc-studio/>

GitHub Pagesで、ソフトの操作とサービス設計思想を紹介するデモです。学校で実データを扱うサービス運用には、別途サーバー版を配置してください。

## localhost版との関係

| 項目 | localhost版 | GitHub公開デモ |
| --- | --- | --- |
| 入口 | `http://localhost:3000/` | 上記の公開URL |
| 実行 | Node.jsサーバーとReact | ブラウザー内のReact |
| 保存先 | 既存のSQLite・画像ストア | 閲覧者のlocalStorage |
| アカウント | デモ・発行アカウント認証 | 企業・教員・生徒の役割切替 |
| 編集の共有 | 同じサーバーの利用者 | 同じブラウザー内の役割間のみ |
| ビルド出力 | `client/dist` | `client/dist-pages` |

公開版のビルドと配置は、localhostの `.env`、DB、アップロード画像、保存済みデータ、通常のビルド出力を変更しません。両者のデータは同期しません。

## 体験できること

1. 企業：架空の企業コンテンツから50分・100分の教材草案を作成。学習指導要領の対応候補・原文の根拠を確認し、目標・活動・評価を編集して提供。
2. 教員：教材を自校用に複製し、自校の目標と単元の位置付けを記入。内容を確認・承認したうえで授業を作成し、活動を進行。
3. 生徒：授業前後の理解度、学び、次の行動、関心を保存。探究4STEPと教員の共有メモ、キャリア画面を確認。
4. mirAI連携候補：共有候補項目のJSONを確認・ダウンロード。これは接続方式の提案で、実際の送信・取込成功を示しません。

初期データと画像は架空です。教材変換はルール処理で、有料AIを呼び出しません。対応候補は学習指導要領への適合を保証せず、公式資料と自校の計画に照らした教員の確認を必要とします。理解度は本人の自己評価で、成績や因果効果ではありません。

## 公開版に含めないもの

- 実アカウントの認証・発行・権限管理、複数端末や他校との同期
- 手帳画像のアップロード・OCR、AIコメント生成、運営KPIと実データの分析
- 副担任mirAIなど外部サービスへのAPI接続
- 生徒の個人情報、企業の機密、添付資料原本、秘密鍵、サーバーDB

ブラウザーのデータ消去やプライベートモード終了などで編集が失われる場合があります。「デモを初期状態に戻す」は公開デモ専用の保存内容だけを初期化します。サイトは誰でも閲覧できます。検索抑制の指定はアクセス制御ではありません。実在する生徒の情報や企業の機密は入力しないでください。

## 更新と確認

```bash
npm --prefix client ci
npm --prefix client run build -- --mode pages
node scripts/check-pages-build.mjs
node --test tests/public-demo.test.js
npm --prefix client run preview -- --mode pages
```

`client/vite.config.js` が `pages` モード時だけ入口と配下パスを切り替えます。`.github/workflows/pages.yml` は `main` の更新時に公開版をビルド・検査し、`client/dist-pages` だけをGitHub Pagesに配備します。サーバー全機能版のデプロイとは独立しています。

公開版の保存データ検証、教材コピー・授業スナップショットの独立性、破損データや保存不可への対応を自動テストします。公開前には企業→教員→生徒の一連の操作、PC・スマートフォン表示、再読込後の保存を確認します。
