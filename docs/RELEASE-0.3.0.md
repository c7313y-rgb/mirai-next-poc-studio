## 互換性と運用上の変更

- 既存DBへ授業前測定テーブルを追加します。既存回答を削除せず、回想式評価を `legacy_response` として区別します。
- 出力スキーマが0.3になりました。取込先へ業種・教科の項目を確認してから受け渡してください。
- `BACKUP_ENCRYPTION_KEY` が必要です。旧平文バックアップは変更しません。
- 実AIの既定月間上限3,000は呼出数です。OCRとコメントは別の呼出です。320人の全規模運用前には実績を踏まえて枠を調整します。
- 初期PWを変えていない教員・企業アカウントは、直接APIを呼んでも業務機能を使えません。
- 下書きはブラウザ内です。共有端末では利用後に削除します。端末下書きをクラウド保存と誤認しないでください。

## 実環境で残る受入

国内クラウド・HTTPS・DNS・IAM・鍵保管、別障害領域へのバックアップ複製、実AIの品質と費用、本番設定でのDocker/Compose起動、学校端末/回線/カメラ、1クラス提出と100名同時操作、先方のCSV/JSON取込、学校の説明・同意と要確認時の対応を確認します。

コード `89610aa` の[GitHub CI](https://github.com/c7313y-rgb/mirai-next-poc-studio/actions/runs/35288586735)で、53件のテスト、クライアントビルド、Dockerのビルドと起動確認が成功しました。コンテナ起動は `AI_PROVIDER=mock` による検証で、実AI接続・本番クラウド受入を意味しません。

まず1校1クラスで実地受入を行います。リアルタイムAPI、SSO、複数台構成、24時間対応、教材の高度生成は別途判断します。
