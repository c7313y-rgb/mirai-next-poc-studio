# サービス設計思想の公開ページ

2026-09-18。提供者の構想資料をもとに、目指す学びの姿を利用者が理解できる説明として再構成しました。原本PDF、全文転載、署名、内部の投資案は公開アプリに含めません。

## 入口

- 公開ページ：`#/about`（`#/approach` も同じページ）。未ログインでも閲覧できます。
- ログイン画面：短い思想の導入と詳細ページへのリンク。利用画面の選択やログインを優先し、説明の閲覧を必須にしません。
- ログイン後：全役割の画面フッターにリンク。企業・教員・生徒のホームでは、それぞれの行動に対応する小さな案内を表示します。
- 説明ページの上部と末尾からログイン画面または本人のホームへ戻れます。ポップアップや初回強制表示は設けません。

## 保全した意図

1. 日常の手帳とデジタルの振り返りから、自分の関心に気づく。
2. 企業・地域のテーマを広く学び、確かめたい問いを自分で選ぶ。
3. 日常の生活圏の外へ出て、現場の当事者と対話し、事実と感情を記録する。
4. 紙の手帳へ手書きで戻し、教員との対話を通して、本人が理由と次の行動を言葉にする。

原本の4 STEPを維持し、最後の段階に含まれる「手帳での内省→教員の対話→本人の自己決定」を明示しています。広い社会学習から一つの現場を深く知る流れと、日常・越境・内省を繰り返す3年間の構想も説明します。

## 現版との区別

- 企業の教材草案・対応候補、教員の最終編集と承認、授業、タグに基づくテーマ候補、探究記録、本人にも共有する面談メモを現版で体験できる機能として紹介します。
- 教材化と推薦はローカルの規則、探究の問いかけは固定文、デモの手帳OCR・コメントは模擬応答です。独立したAI対話エンジンや強み・能力・職業適性の自動評価を実装したように表現しません。
- JMAM企業・地域ネットワークへの実接続、受入契約・越境体験の手配、入試・合格体験談DB、3年間の同意・学年移管、本番mirAI API接続は未実装の範囲として表示します。約6,000社の実接続や提携実績を宣伝しません。
- 入試の規制対応や合格、学習効果、自動の学習指導要領適合を保証する文言は使用しません。構想を機能の完成や現場実証の成功と混同しません。
- 使用画像は既存の3点のみ。架空のAI生成イメージと表示し、実企業や実施実績の写真と誤認させません。[ASSETS.md](ASSETS.md)を参照してください。
