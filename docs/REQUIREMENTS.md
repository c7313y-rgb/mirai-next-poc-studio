# PoCの機能と評価範囲

このPoCは、企業のコンテンツを教員が授業に取り入れ、生徒の振り返りを蓄積する流れを検証するWebアプリです。学校での使いやすさ、企業の継続参加意向、学習記録を副担任mirAIへ引き継げるかを評価します。公開デモの数値は架空のデータによる動作例で、実証成果ではありません。

## 利用者と今回の追加機能

| 利用者 | 主な操作と閲覧範囲 |
| --- | --- |
| 企業 | 自社コンテンツの入力、50分/100分の授業案作成、編集、学校への提供、自社教材の匿名集計 |
| 教員 | 提供教材の採用、学習目標・活動・時間・確認観点の最終編集と承認、担当クラスへの授業配信・進行、提出と学習振り返りの確認 |
| 生徒 | 自分のクラスの授業、撮影・読み取り結果の確認修正、記録提出、関心の表明、授業前後の自己評価・学び・次の行動、キャリア記録と共有予定データの確認 |
| 運営 | 利用者・テーマ・アンケートの管理、12 KPI、匿名要約の承認、連携ファイル出力、操作ログ |

企業・教員・生徒に専用のアクセス画面を用意し、運営画面も維持します。デモ簡易ログインと発行ID・パスワードによるログインを切り替えます。教員が採用した教材は教員用の複製として編集し、授業作成時の内容を保存します。

学習効果の表示は授業前後の理解度の自己評価（1〜5）と振り返りに基づきます。成績、職業適性、授業による因果効果、受験成果を測定したものではありません。

## KPIの定義

以下の目標はすべて**案**です。実証開始前に集計期間、対象者、除外期間、分母とともに合意し、運営設定へ反映します。データがない場合や分母がゼロの場合は、達成と判断しません。

| ID | 指標・定義 | 目標案 |
| --- | --- | --- |
| K-S1 | 協力校数：選択した終了日までにテーマ配信を開始、または記録を提出した学校の累計。開始日では絞らない | 3校以上 |
| K-S2 | 生徒アクティブ率：対象生徒のうち週1回以上記録を提出した割合の週平均 | 50%以上 |
| K-S3 | 継続利用率：各校の実証開始2週間の提出者のうち、基準終了日の直前14日にも提出した割合。開始日フィルタで基準集団を絞らない | 60%以上 |
| K-S4 | 教員の声：期間内に配信を開始した授業のうち、期間内に授業後アンケート回答を得た配信授業の割合 | 回収率80%以上 |
| K-S5 | 授業のしやすさ：K-S4と同じ範囲の教員回答における5段階評価平均 | 4.0以上 |
| K-S6 | 生徒の声：アンケート回答率と5段階評価平均 | 回答率60%以上、平均3.5以上 |
| K-C1 | 賛同企業数：K-C2の対象テーマを提供した企業数 | 5社以上 |
| K-C2 | 提供テーマ数：終了日までに公開した、現在公開中のテーマ累計。開始日では絞らない | 5本以上 |
| K-C3 | 関心反応率：期間内に初回閲覧した生徒とテーマの組のうち、期間内の「関心あり」が残っている割合 | 30%以上 |
| K-C4 | 継続参加意向：K-C1の参加企業のうち、期間内の最終回答が「継続したい」の企業の割合。未回答は分子に含めない | 60%以上 |
| K-X1 | テーマ記録件数：K-C2の各テーマに紐づく、期間内に提出された生徒記録数。画面主値はテーマ間の最少件数 | すべての対象テーマで20件以上 |
| K-X2 | データ連携充足率：選択期間・学校の提出記録を使い、必須連携項目のうち実データを1件以上出力できる項目の割合 | 100% |

対象生徒は現在有効な生徒アカウントです。学校フィルタは対象校の生徒・配信・記録に適用します。K-C1/K-C2/K-X1のテーマ集合を学校で絞るときは、終了日までにその学校への配信を開始したテーマを対象とします。公開状態の変更履歴や過去の在籍状態を復元する機能はありません。

K-S2は月曜始まりで週を区切ります。週開始日が設定した除外期間内の週は除外します。期間の端で一部の日しか含まれない週は、完全な週がある場合には平均から除外し、完全な週がない場合だけ暫定集計します。K-S3の基準終了日は「選択終了日・実証終了日・本日」の最も早い日で、実証終了日より前は暫定値です。K-S4はテーマ配信単位での回答回収であり、すべての実施授業を自動的に把握する指標ではありません。

K-C3は「生徒×テーマ」を集計単位とします。現在のデータ構造は初回閲覧日時と現在の関心選択を保持しているため、再閲覧や、取り消した関心選択の履歴は含みません。期間を変更した場合も同じ初回閲覧の母集団を分母・分子に適用します。K-C4は同じ企業の回答が複数ある場合に、期間内の最終回答を採用します。

K-X1はすべての対象テーマで目標件数以上になった場合のみ達成と判定します。平均件数は補足値です。K-X2は対象記録がない場合には未計測とします。100%は全レコードが完全であることや、接続先で取り込めたことを意味しません。必須項目ごとの対象件数・充足件数と、相手側の取込結果を別に評価します。

## AIと教材変換の範囲

既定の `AI_PROVIDER=mock` は外部送信を行わず、OCRはダミー応答、コメントやタグ等はデモ処理です。実際の手書き文字を読み取るには、別途AIサービスの設定と精度確認が必要です。

企業コンテンツから授業案への変換は、今回の版では**テンプレート変換**です。入力内容を授業の5段階へ組み込み、学習目標・活動・教員向け補足を作ります。外部の高度モデルを呼び出した生成ではありません。企業と教員が事実関係、公開範囲、年齢への適切さを確認してから授業に使います。

実AIの切替対象であるOCR・記録分析・要約と、テンプレートによる授業案作成は別機能です。AIコメントは学習を支えるもので、採点や心理診断を行いません。要確認表示は教員の気づきを補助し、学校の見守り体制を代替しません。

## 副担任mirAIへ共有するデータ

生徒画面では、自分の関心タグ、学習記録、次の行動と、共有予定のデータを確認できます。**現版は共有プレビューであり、外部送信・先方取込の確認は行っていません。** 運営画面ではCSV/JSONを出力できます。接続先の仕様確定後、項目とタグの対応を合わせて取込試験を行います。

共有の基本項目は仮名ID、学校コード・学年・クラス、記録日・種類、本人確認済みの記録テキスト、関心タグ、テーマ・企業IDと企業分野、振り返り要約です。体験記録と教員コメントは任意です。標準出力は企業業種と教科を別項目とし、原本に列挙されない生徒アンケート自由記述は含めません。終了日後の教員コメントも含めません。学習振り返りなどの拡張項目は、採用可否を接続先と合意する必要があります。

撮影画像、要確認フラグ、利用ログ、氏名は共有プレビューに含めません。仮名化された記録にも自由記述が含まれるため、個人情報として適切な閲覧権限と保管期間を設定します。企業には個別記録を渡さず、集計と承認済み匿名要約を提供します。少人数の学習反応は非表示にします。

## 検証の限界

実物の手帳でのOCR精度、学校端末での撮影、同時利用時の性能、国内AI処理と保存、mirAI側の取込成功は、デモの動作確認だけでは検証できません。公開リポジトリは実証前の実装を共有するもので、実運用環境の保証ではありません。運用準備は [OPERATIONS.md](OPERATIONS.md) を参照してください。
