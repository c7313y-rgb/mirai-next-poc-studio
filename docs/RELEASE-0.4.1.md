# v0.4.1 — ローカル起動の改善と学びの設計思想

2026-09-18

## 変更内容

URLだけのショートカットでは停止中のサーバーを起動できなかったため、Mac用の起動ランチャーを追加しました。既存の設定・保存先を維持し、ヘルス確認後に画面を開きます。起動元の終了後も動作し、二重起動の防止、状態確認、管理対象だけの停止、起動ログに対応します。OSへの自動起動登録は行いません。

提供者の構想をもとに公開ページ `#/about` を追加しました。デジタルでの気づきから企業テーマ・越境体験へ進み、手帳の内省と教員との対話を通して本人が選択する思想を訴求します。ログイン画面・各役割ホーム・フッターに入口を設けました。現版で体験できる機能と、実地手配・外部接続・3年間の本格運用という将来構想を区別しています。

スマートフォンで画面下のログインボタンを押した際、ホームも途中までスクロールした位置で開く問題を修正しました。アカウントが切り替わると画面先頭から表示します。

既存の生成画像を再利用し、新しい有料APIや月額契約は追加していません。今回の改修による必須のサービス利用料増加はありません。

## 更新時の扱い

- `.env`、DB、アップロード画像を保持します。データの再投入は不要です。
- 依存関係の取得後に画面をビルドします。Macのクラウド上でファイルが未取得の場合はローカルへ取得してください。
- 起動方法は [LOCAL-DEMO.md](LOCAL-DEMO.md)、公開ページの表現方針は [SERVICE-DESIGN.md](SERVICE-DESIGN.md) を参照してください。

## 検証

認証・権限・教材・授業・KPI・探究・連携出力と、ランチャーを含む79テストが成功しました。画面の本番ビルドも成功しています。ランチャーは設定保持、起動元終了後の継続、二重起動防止、他サービス保護、起動失敗ログ、設定変更後の停止、生存中ソケットの保護を確認しました。ローカル実起動、企業・教員・生徒の画面、未ログインでの設計思想ページ、390px幅の表示をブラウザーで確認し、横方向のはみ出しがないこととログイン後に画面先頭を表示することを検証しました。

本番サーバーへの配備、実AIの品質、外部mirAIの取込、学校での効果測定は今回の検証に含めません。
